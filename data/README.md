# Data

The project uses `Data_Housing_Madrid.csv`, supplied as academic coursework material.

The dataset is not redistributed in this public portfolio repository because the coursework did not provide a public redistribution license.

The analysis uses these fields:

- `house.price` — housing price in euros per square metre
- `historical` — indicator for Madrid's historical centre
- `longitude`
- `latitude`

To reproduce the notebook, place the original file here:

`data/Data_Housing_Madrid.csv`
