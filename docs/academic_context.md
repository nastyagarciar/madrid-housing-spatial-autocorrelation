# Academic Context

The evaluation task describes the Madrid housing data as originating from:

José María Montero, Román Mínguez and Gema Fernández-Avilés (2018),  
*Housing price prediction: parametric vs semiparametric spatial hedonic models*,  
Journal of Geographical Systems, 20, 27–55.

DOI: `10.1007/s10109-017-0257-y`

The coursework objective for the relevant question is to quantify spatial autocorrelation in price per square metre for Madrid's **historical centre**.

This portfolio project reconstructs that objective as a standalone spatial-statistics analysis rather than reproducing the full multiple-choice quiz.
